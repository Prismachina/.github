# Prismachina

Retracing the history of modern operating systems.

Prismachina is an experiment in rebuilding the path from early Unix to modern operating systems. 

The project begins with Unix v0 and the assembler `as`. From there, we build our own toolchain, languages, and operating system environment.

At each stage, we work within the constraints of the hardware available at the time, and each language, compiler, and tool must be designed and implemented within the environment that we have already built. 

Prismachina aims to answer the following questions through implementation:
 - Why did systems designers choose these approaches?
 - Which ambitious ideas were abandoned, and which of them might reshape operating systems if they had a chance?
 - Given what we know in 2026, would we make the same decision under the constraints of the 1960s?
 - What would we build differently if we were given the same starting point? Where would we end up?
